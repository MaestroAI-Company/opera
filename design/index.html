App : Opera IA : Maestro Local & privé

Vue d'ensemble

Warm, éditorial et légèrement technique : un fond crème #FFF5EC, un unique accent rouge #FF1A1A, des titres serif Petrona et un chrome UI monospace IBM Plex Mono qui évoque un terminal. Tout tourne en local (Ollama, Whisper, Gemini Nano). Un mode incognito violet-gris remplace entièrement l'identité rouge.

Règles d'or : le rouge est la seule couleur d'interaction, réservée à l'action la plus importante de l'écran. Bordure "sticker" de 2px, rayon par défaut 10px, ombres dures sans blur.

Composants

Boutons

Appuyez sur un bouton pour voir l'état pressé. Primary = rouge #FF1A1A → #D61515 · Ghost = blanc 2px · Danger = rouge sur fond clair.

Champs de saisie

Pilule blanche bordée 2px, rayon 10px, texte mono 14px, placeholder #AAAAAA, focus rouge. Icône 18×18 en tête de champ (comme le champ « Ollama server »).

Chat

Bonjour ! Je suis Maestro. Posez-moi une question, je réponds localement, sans envoyer vos données.
Explique-moi comment chiffrer mes notes.
Cette conversation disparaît pour toujours.

Bulles utilisateur : pilules rouges alignées à droite (max 80%), 10px, texte blanc. Messages IA : pleine largeur, markdown, sans bulle. Composer : pilule 56px, bordure 2px, glow coloré (rouge / #565A75 en incognito), icônes + / micro / envoi teintées en blanc. Appuyez pour l'état pressé (fond éclairci + scale 1.05).

À faire / à éviter

À faire

  • Utiliser le rouge uniquement pour l'action la plus importante de l'écran
  • Toujours tirer les valeurs des tokens de constants/theme.ts
  • Petrona pour les displays, Figtree pour la lecture, Plex Mono pour le chrome UI
  • Garder un recolor incognito cohérent (remplacer chaque rouge par #565A75)
  • Préférer les ombres sticker et les contours 2px
  • Garder le texte du corps au-dessus de WCAG AA

À éviter

  • Utiliser le rouge pour la décoration ou plusieurs actions simultanées
  • Hardcoder couleurs, polices ou rayons hors tokens
  • Mélanger serif et mono dans un même titre
  • Dépasser 10px de rayon sur des cartes denses en données
  • Ajouter de grosses ombres portées floues
  • Confondre Opera (l'app) et Maestro (l'IA)
